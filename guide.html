网页版使用手册

不用安装 APK。用手机浏览器打开 JavaQuest，像网页一样学习、写 Java、走剧情。这份手册分别说明 iPhone/iPad 和 Android 的打开方式、添加到桌面、键盘操作、进度保存和常见问题。

网页版的进度保存在当前浏览器里，不会自动同步到其他手机或电脑。换设备、换浏览器或清除网站数据，进度会重新开始。

1. 先选你的设备

SAFARI · IOS 15+

第一次打开

1
打开 Safari。iPhone 上的 Chrome、Edge 也使用 WebKit，但进度和 Safari 分开保存，建议固定用一个浏览器。
2
在地址栏输入本站地址，或从聊天里点开链接。
3
等待首页出现“选择模式”。第一次运行代码会下载 Java 运行时，可能需要十几秒。
HOME SCREEN

添加到主屏幕

1
点 Safari 底部的分享按钮（方框向上箭头）。
2
向下找到“添加到主屏幕”，改名为 JavaQuest，点“添加”。
3
以后从桌面图标进入，界面更接近全屏。它不是 App Store 安装包，仍然是一个网页快捷方式。

iPhone / iPad 操作要点

  • 编辑器里有“补全”按钮；iPhone 键盘没有 Ctrl+Space，点按钮即可弹出补全。
  • 键盘挡住代码时，点键盘右上角“完成”收起，或上下滑动页面。
  • 横屏或 iPad 分屏时布局会自动变宽；代码区变高，适合长代码。
  • 不要用无痕浏览长期学习：关闭无痕窗口后，localStorage 里的进度可能丢失。
  • 如果更新后仍是旧页面，关闭标签页重新打开，或到 Safari 设置里清除该网站数据。
iOS 的“清除历史记录与网站数据”会删除本站在本机的进度。清除前请确认不需要保留。
CHROME · ANDROID 10+

第一次打开

1
用 Chrome 或 Edge 打开本站。建议固定用一个浏览器，避免进度分散。
2
等待首页加载。若只看到加载页，先检查网络，再刷新一次。
3
进入“闯关”或“自由编程”，运行第一个 Hello World。
HOME SCREEN / INSTALL

添加到主屏幕

1
点 Chrome 右上角三个点。
2
选择“添加到主屏幕”或“安装应用”（不同版本文字不同）。
3
确认名称后添加。以后从桌面图标打开，仍然是同一个网页站点。

Android 操作要点

  • 编辑器有行号、语法高亮和“补全”按钮；外接键盘可以用 Ctrl+Space 或 Cmd+Space。
  • 系统返回键可能直接退出网页，而不是返回上一关；优先使用页面里的“← 返回”。
  • 分屏、折叠屏展开时布局会重排；如果代码区太窄，横屏或全屏浏览器。
  • Chrome 的“清除浏览数据”会删除本站进度；只清缓存通常不会，但清“网站数据”会。
  • 省电模式或后台限制可能导致首次 Java 运行时下载变慢，建议在 Wi-Fi 下第一次运行。
Android 的“无痕模式”不适合长期学习：关闭标签页后，本站保存的进度不会保留。

网页版里有什么

  • 闯关模式：100 个教程关卡，运行代码后自动测试。
  • 剧情模式：30 个故事，1–3 段限时编程，8–9 个结局；故事树只显示你走到过的节点。
  • Java 8 主线：84 关单线剧情，按课程顺序推进。
  • 自由编程：自己写 Java，支持标准输入和错误输出。
  • 冒险手册：每日挑战、Boss Rush、错题本、知识卡牌、成就墙和代码宠物。

代码运行说明

Java 代码在浏览器内执行，不上传服务器。第一次运行需要从 CheerpJ CDN 下载 Java 运行时，因此首次会慢，之后通常更快。页面本身可以打开，但“运行代码”需要能访问 cjrtnc.leaningtech.com。

如果运行按钮一直转圈，先换 Wi-Fi/移动网络，关闭广告拦截或内容拦截器，再刷新重试。

进度和隐私

  • 进度、代码、结局、成就保存在当前浏览器的 localStorage。
  • 没有账号系统，不上传代码，不收集统计。
  • 换手机、换浏览器、清除网站数据都会丢失进度，且无法自动恢复。
  • 首页底部的“清空本地进度”会删除全部本地记录，操作不可撤销。

2. 三分钟上手

1
先跑 Hello World。进入“闯关”第一关，点“运行并测试”，确认代码能跑通。
2
再看一眼 Java 8 主线。主线是单线剧情；如果只想补 Java 8，优先走没有版本标签的关卡。
3
去冒险手册领每日挑战。完成关卡后解锁支线、错题本、Boss Rush 和知识卡牌。
4
把网站加到主屏幕。以后从桌面直接进入，减少找链接的麻烦。

3. 常见问题

页面显示“课程数据加载失败”

通常是 data.js 没有和 index.html 一起部署。网页端已经优先从 data.js 读取课程，不再依赖 JSON 请求；请确认部署目录里有 data.js。然后强制刷新。

报错 “Unexpected token '<'”

这是把 404 HTML 当成 JSON 解析的旧问题。新版应加载 data.js；如果仍出现，说明线上还是旧文件，重新部署并清缓存。

页面能打开，但运行代码失败

先确认网络能访问 cjrtnc.leaningtech.com；关闭内容拦截器；换 Wi-Fi 或移动网络；刷新后再试。首次加载 Java 运行时需要时间。

代码编辑器没有补全

点编辑器右上角的“补全”按钮；外接键盘可用 Ctrl+Space 或 Cmd+Space。若按钮提示组件未加载，检查网络后刷新。

进度突然没了

可能是清除了浏览器网站数据、使用了无痕模式，或换了浏览器/设备。本站没有账号同步，无法从服务器恢复。

手机横屏/折叠屏显示不正常

先旋转屏幕或重新进入页面；代码区会随宽度变化。若仍异常，请反馈机型、系统版本和浏览器版本。

4. 给家长/老师的一句话

本站不需要注册，不上传代码，不包含广告 SDK；学生的代码和进度只保存在这台设备的浏览器里。清理浏览器数据会清空进度，建议固定设备、固定浏览器使用。
